# redisrs v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `redisrs`, an R package that connects to Redis and Valkey through the Rust crate `redis-rs`. It supports AWS ElastiCache with TLS, cluster mode, and IAM.

**Architecture:** A Rust core in `src/rust/` holds the connection, runs commands, converts replies, and signs IAM tokens. Thin R functions wrap the core. The R layer owns retries and token refresh, so Rust never calls back into R. Errors cross the boundary as a plain list of class `redisrs_failure`, and R turns it into a classed condition.

**Tech Stack:** R (>= 4.2) and extendr (`extendr-api` 0.8, `rextendr`). Rust crates: `redis-rs` (sync API, features `cluster` and `tls-rustls`), `hmac` 0.12, `sha2` 0.10, `hex` 0.4. Tests: `testthat` 3, `withr`, Docker with Valkey 8.1, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-11-redis-r-client-design.md`

All paths in this plan are relative to the repository root `~/projects/redisrs`.

## Global Constraints

- Package name: `redisrs`. License: MIT.
- `DESCRIPTION` has `SystemRequirements: Cargo (Rust's package manager), rustc`.
- `paws.common` and `withr` are in `Suggests`, not `Imports`. `Imports` is empty.
- The client always uses RESP3. No user option selects RESP2.
- TLS uses `rustls` with the `ring` crypto provider. `aws-lc-rs` must not be in the dependency tree.
- No `aws-sigv4` and no AWS SDK crates.
- All Rust crates are vendored into `src/rust/vendor.tar.xz`. The built source tarball must be under 5 MB.
- `redis_cmd()` and `redis_pipeline()` refuse `SUBSCRIBE`, `PSUBSCRIBE`, `SSUBSCRIBE`, `MONITOR` (any letter case) with `redis_usage_error`.
- Error classes: `redis_error`, `redis_connection_error`, `redis_auth_error`, `redis_usage_error`. Each one also has `redisrs_error`, `error`, `condition`.
- Connect timeout: 10 seconds. No read timeout.
- Each connection is an R environment of class `redisrs_connection`.
- If `REDISRS_TEST_SERVERS` is not `true`, tests that need a server skip. They always skip on CRAN.

## Review Focus

1. Binary values that are valid UTF-8 but contain a NUL byte, for example `serialize()` output. Expected: they come back as `raw`, never as a broken string. Test in Task 2 and Task 11.
2. A URL with a password in it. Expected: `print(con)` never shows the password. Test in Task 6.
3. Integers above 2^31 and the number formats that R sends, for example `1e6` and `5L`. Expected: `INCRBY k 3000000000` works and `1e6` goes to Redis as `1000000`, not `1e+06`. Test in Task 4 and Task 6.
4. Use of a closed connection, or a connection after a server restart. Expected: a closed connection gives `redis_usage_error` without a retry, and a dropped connection reconnects once. Test in Task 6 and Task 7.
5. A pipeline where one command fails. Expected: the other replies come back, and the failed slot holds a `redis_error` condition object that is not thrown. Test in Task 8.

```rust
use redis::Value;

/// A Redis reply in plain Rust types. `robj.rs` turns it into an R value.
#[derive(Debug, Clone, PartialEq)]
pub enum Reply {
    Nil,
    Int(i64),
    Double(f64),
    Bool(bool),
    Str(String),
    Bytes(Vec<u8>),
    Array(Vec<Reply>),
    Map(Vec<(String, Reply)>),
    Error { code: String, message: String },
}

/// R strings cannot hold NUL, so bytes with NUL stay raw even when valid UTF-8.
fn bytes_reply(b: Vec<u8>, raw: bool) -> Reply {
    if raw || b.contains(&0) {
        return Reply::Bytes(b);
    }
    match String::from_utf8(b) {
        Ok(s) => Reply::Str(s),
        Err(e) => Reply::Bytes(e.into_bytes()),
    }
}

fn key_string(v: Value) -> String {
    match from_value(v, false) {
        Reply::Str(s) => s,
        Reply::Int(i) => i.to_string(),
        Reply::Double(d) => d.to_string(),
        Reply::Bytes(b) => String::from_utf8_lossy(&b).into_owned(),
        other => format!("{other:?}"),
    }
}

pub fn from_value(v: Value, raw: bool) -> Reply {
    match v {
        Value::Nil => Reply::Nil,
        Value::Int(i) => Reply::Int(i),
        Value::Double(d) => Reply::Double(d),
        Value::Boolean(b) => Reply::Bool(b),
        Value::Okay => Reply::Str("OK".into()),
        Value::SimpleString(s) => Reply::Str(s),
        Value::BulkString(b) => bytes_reply(b, raw),
        Value::VerbatimString { text, .. } => Reply::Str(text),
        Value::Array(items) | Value::Set(items) => {
            Reply::Array(items.into_iter().map(|x| from_value(x, raw)).collect())
        }
        Value::Push { data, .. } => {
            Reply::Array(data.into_iter().map(|x| from_value(x, raw)).collect())
        }
        Value::Map(pairs) => Reply::Map(
            pairs
                .into_iter()
                .map(|(k, v)| (key_string(k), from_value(v, raw)))
                .collect(),
        ),
        Value::Attribute { data, .. } => from_value(*data, raw),
        Value::ServerError(e) => Reply::Error {
            code: e.code().to_string(),
            message: e.details().unwrap_or("").to_string(),
        },
        // BigNumber and any variant added later: keep the text form.
        other => Reply::Str(format!("{other:?}")),
    }
}
```

```rust
use hmac::{Hmac, Mac};
use sha2::{Digest, Sha256};

type HmacSha256 = Hmac<Sha256>;

pub struct TokenRequest<'a> {
    pub cache_name: &'a str,
    pub user_id: &'a str,
    pub region: &'a str,
    pub access_key: &'a str,
    pub secret_key: &'a str,
    pub session_token: Option<&'a str>,
    pub amz_date: &'a str,
    pub serverless: bool,
}

/// SigV4 URI encoding: everything except A-Z a-z 0-9 - _ . ~ is %XX.
fn enc(s: &str) -> String {
    let mut out = String::with_capacity(s.len());
    for b in s.bytes() {
        match b {
            b'A'..=b'Z' | b'a'..=b'z' | b'0'..=b'9' | b'-' | b'_' | b'.' | b'~' => {
                out.push(b as char)
            }
            _ => out.push_str(&format!("%{b:02X}")),
        }
    }
    out
}

fn hmac(key: &[u8], msg: &str) -> Vec<u8> {
    let mut m = HmacSha256::new_from_slice(key).expect("HMAC accepts any key length");
    m.update(msg.as_bytes());
    m.finalize().into_bytes().to_vec()
}

/// Presigned `GET http://<cache_name>/?Action=connect&User=<user_id>`, as botocore builds it.
/// Parameter order in the output matches botocore: operation params, then auth params.
pub fn presign(r: &TokenRequest) -> String {
    let date = &r.amz_date[..8];
    let scope = format!("{date}/{}/elasticache/aws4_request", r.region);

    let mut op: Vec<(&str, String)> = vec![("Action", "connect".into()), ("User", r.user_id.into())];
    if r.serverless {
        op.push(("ResourceType", "ServerlessCache".into()));
    }
    let mut auth: Vec<(&str, String)> = vec![
        ("X-Amz-Algorithm", "AWS4-HMAC-SHA256".into()),
        ("X-Amz-Credential", format!("{}/{scope}", r.access_key)),
        ("X-Amz-Date", r.amz_date.into()),
        ("X-Amz-Expires", "900".into()),
        ("X-Amz-SignedHeaders", "host".into()),
    ];
    if let Some(t) = r.session_token {
        auth.push(("X-Amz-Security-Token", t.into()));
    }

    let encoded: Vec<(String, String)> = op
        .iter()
        .chain(auth.iter())
        .map(|(k, v)| (enc(k), enc(v)))
        .collect();
    let mut sorted = encoded.clone();
    sorted.sort();
    let join = |pairs: &[(String, String)]| {
        pairs.iter().map(|(k, v)| format!("{k}={v}")).collect::<Vec<_>>().join("&")
    };

    let empty_hash = hex::encode(Sha256::digest(b""));
    let canonical = format!("GET\n/\n{}\nhost:{}\n\nhost\n{empty_hash}", join(&sorted), r.cache_name);
    let to_sign = format!(
        "AWS4-HMAC-SHA256\n{}\n{scope}\n{}",
        r.amz_date,
        hex::encode(Sha256::digest(canonical.as_bytes()))
    );
    let key = hmac(
        &hmac(&hmac(&hmac(format!("AWS4{}", r.secret_key).as_bytes(), date), r.region), "elasticache"),
        "aws4_request",
    );
    let signature = hex::encode(hmac(&key, &to_sign));
    format!("{}/?{}&X-Amz-Signature={signature}", r.cache_name, join(&encoded))
}
```

```r
as_args <- function(dots, call = NULL) {
  if (length(dots) == 0L) stop(usage_error("no command given", call))
  out <- list()
  for (x in dots) {
    if (is.raw(x)) {
      out[[length(out) + 1L]] <- x
      next
    }
    if (length(x) == 0L) stop(usage_error("empty or NULL argument", call))
    if (!is.atomic(x)) stop(usage_error("arguments must be character, numeric, logical or raw", call))
    if (anyNA(x)) stop(usage_error("NA is not a valid Redis argument", call))
    s <- if (is.character(x)) {
      enc2utf8(x)
    } else if (is.logical(x)) {
      ifelse(x, "1", "0")
    } else if (is.integer(x)) {
      as.character(x)
    } else if (is.numeric(x)) {
      format_number(x)
    } else {
      stop(usage_error("arguments must be character, numeric, logical or raw", call))
    }
    for (el in s) out[[length(out) + 1L]] <- charToRaw(el)
  }
  name <- tryCatch(toupper(rawToChar(out[[1L]])), error = function(e) "")
  if (name %in% mode_commands) {
    stop(usage_error(paste0(name, " changes the connection mode and is not supported by redis_cmd()"), call))
  }
  out
```

```rust
use extendr_api::prelude::*;
use redis::{ErrorKind, RedisError};

fn kind_of(e: &RedisError) -> &'static str {
    if matches!(e.code(), Some("WRONGPASS") | Some("NOAUTH")) || e.kind() == ErrorKind::AuthenticationFailed {
        return "auth";
    }
    if e.is_io_error() || e.is_connection_dropped() || e.is_connection_refusal() || e.is_timeout() {
        return "connection";
    }
    match e.kind() {
        ErrorKind::IoError | ErrorKind::ClusterConnectionNotFound => "connection",
        ErrorKind::InvalidClientConfig | ErrorKind::ClientError => "usage",
        _ => "server",
    }
}

    let mut r: Robj = list!(kind = kind, code = code, message = message).into();
    r.set_class(&["redisrs_failure"]).expect("set class on a list");
    r
}

pub fn failure(e: &RedisError) -> Robj {
    failure_msg(kind_of(e), e.code().unwrap_or(""), &e.to_string())
```

```rust
use crate::reply::Reply;
use extendr_api::prelude::*;

pub fn to_robj(r: Reply) -> Robj {
    match r {
        Reply::Nil => Robj::from(()),
        // R integer has 32 bits, so all Redis integers become doubles.
        Reply::Int(i) => Robj::from(i as f64),
        Reply::Double(d) => Robj::from(d),
        Reply::Bool(b) => Robj::from(b),
        Reply::Str(s) => Robj::from(s),
        Reply::Bytes(b) => Raw::from_bytes(&b).into(),
        Reply::Array(items) => List::from_values(items.into_iter().map(to_robj)).into(),
        Reply::Map(pairs) => {
            let (names, values): (Vec<String>, Vec<Robj>) =
                pairs.into_iter().map(|(k, v)| (k, to_robj(v))).unzip();
            List::from_names_and_values(names, values).expect("names match values").into()
        }
        // Only nested errors reach here (pipeline slots). They are returned, not thrown.
        Reply::Error { code, message } => {
            let text = format!("{code} {message}").trim().to_string();
            let mut r: Robj = list!(message = text, call = (), code = code).into();
            r.set_class(&["redis_error", "redisrs_error", "error", "condition"])
                .expect("set class on a list");
            r
        }
    }
}
```

```rust
use redis::cluster::{ClusterClientBuilder, ClusterConnection};
use redis::{Client, Cmd, Connection, ErrorKind, IntoConnectionInfo, ProtocolVersion, RedisError, RedisResult, Value};
use std::time::Duration;

const CONNECT_TIMEOUT: Duration = Duration::from_secs(10);

pub enum Conn {
    Plain(Connection),
    Cluster(ClusterConnection),
    Closed,
}

pub struct Auth {
    pub username: Option<String>,
    pub password: Option<String>,
}

pub fn closed_error() -> RedisError {
    RedisError::from((ErrorKind::ClientError, "connection is closed"))
}

pub fn open(url: &str, cluster: bool, auth: &Auth) -> RedisResult<Conn> {
    let mut info = url.into_connection_info()?;
    info.redis.protocol = ProtocolVersion::RESP3;
    if auth.username.is_some() {
        info.redis.username = auth.username.clone();
    }
    if auth.password.is_some() {
        info.redis.password = auth.password.clone();
    }
    if cluster {
        let mut b = ClusterClientBuilder::new(vec![info.clone()])
            .use_protocol(ProtocolVersion::RESP3)
            .connection_timeout(CONNECT_TIMEOUT);
        if let Some(u) = &info.redis.username {
            b = b.username(u.clone());
        }
        if let Some(p) = &info.redis.password {
            b = b.password(p.clone());
        }
        Ok(Conn::Cluster(b.build()?.get_connection()?))
    } else {
        let client = Client::open(info)?;
        Ok(Conn::Plain(client.get_connection_with_timeout(CONNECT_TIMEOUT)?))
    }
}

impl Conn {
    pub fn query(&mut self, cmd: &Cmd) -> RedisResult<Value> {
        match self {
            Conn::Plain(c) => cmd.query(c),
            Conn::Cluster(c) => cmd.query(c),
            Conn::Closed => Err(closed_error()),
        }
    }
}
```

```rust
use extendr_api::prelude::*;

mod conn;
mod errors;
mod iam;
mod reply;
mod robj;

pub struct RedisConn {
    conn: conn::Conn,
}

fn opt_string(x: &Robj) -> Option<String> {
    if x.is_null() {
        None
    } else {
        x.as_str().map(str::to_string)
    }
}

fn build_cmd(args: &List) -> std::result::Result<redis::Cmd, String> {
    let mut cmd = redis::Cmd::new();
    for (_, a) in args.iter() {
        let bytes = a.as_raw_slice().ok_or("internal: argument is not a raw vector")?;
        cmd.arg(bytes);
    }
    Ok(cmd)
}

#[extendr]
impl RedisConn {
    fn cmd(&mut self, args: List, raw: bool) -> Robj {
        let cmd = match build_cmd(&args) {
            Ok(c) => c,
            Err(m) => return errors::failure_msg("usage", "", &m),
        };
        match self.conn.query(&cmd) {
            Ok(v) => robj::to_robj(reply::from_value(v, raw)),
            Err(e) => errors::failure(&e),
        }
    }

    fn close(&mut self) {
        self.conn = conn::Conn::Closed;
    }
}

#[extendr]
fn rs_connect(url: &str, cluster: bool, username: Robj, password: Robj) -> Robj {
    let auth = conn::Auth {
        username: opt_string(&username),
        password: opt_string(&password),
    };
    match conn::open(url, cluster, &auth) {
        Ok(c) => RedisConn { conn: c }.into(),
        Err(e) => errors::failure(&e),
    }
}

extendr_module! {
    mod redisrs;
```

```r
#' Connect to Redis or Valkey
#'
#' @param url A URL such as `redis://host:6379`, `rediss://host:6380` for TLS,
#'   or `redis+unix:///path/to.sock`. A password in the URL is used for AUTH.
#' @param cluster If `TRUE`, use Redis Cluster mode.
#' @param username User name for AUTH. It replaces the user name in `url`.
#' @param token_fn A function without arguments that returns the password.
#'   It is called at each connect and reconnect, for example to get a fresh
#'   IAM token.
#' @return An object of class `redisrs_connection`.
#' @export
redis_connect <- function(url, cluster = FALSE, username = NULL, token_fn = NULL) {
  call <- sys.call()
  if (!is.character(url) || length(url) != 1L || is.na(url)) {
    stop(usage_error("url must be one string", call))
  }
  if (!is.null(token_fn) && !is.function(token_fn)) {
    stop(usage_error("token_fn must be a function or NULL", call))
  }
  con <- new.env(parent = emptyenv())
  con$url <- url
  con$cluster <- isTRUE(cluster)
  con$username <- username
  con$token_fn <- token_fn
  con$ptr <- NULL
  class(con) <- "redisrs_connection"
  res <- connect_ptr(con)
  if (is_failure(res)) raise_failure(res, call)
  con
}

connect_ptr <- function(con) {
  password <- if (is.null(con$token_fn)) NULL else con$token_fn()
  res <- rs_connect(con$url, con$cluster, con$username, password)
  if (!is_failure(res)) con$ptr <- res
  res
}

check_con <- function(con, call = NULL) {
  if (!inherits(con, "redisrs_connection")) {
    stop(usage_error("con must be a redisrs_connection", call))
  }
  if (is.null(con$ptr)) stop(usage_error("connection is closed", call))
  invisible(con)
}

#' Close a connection
#' @param con A connection from [redis_connect()].
#' @export
redis_close <- function(con) {
  if (inherits(con, "redisrs_connection") && !is.null(con$ptr)) {
    con$ptr$close()
    con$ptr <- NULL
  }
  invisible(NULL)
}

redact_url <- function(url) sub("//[^@/]*@", "//***@", url)

#' @export
print.redisrs_connection <- function(x, ...) {
  state <- if (is.null(x$ptr)) "closed" else "open"
  mode <- if (x$cluster) "cluster" else "single"
  cat("<redisrs_connection> ", redact_url(x$url), " (", mode, ", ", state, ")\n", sep = "")
```

```rust
    fn pipeline(&mut self, cmds: List) -> Robj {
        let mut built = Vec::with_capacity(cmds.len());
        for (_, c) in cmds.iter() {
            let args = match c.as_list() {
                Some(l) => l,
                None => return errors::failure_msg("usage", "", "internal: command is not a list"),
            };
            match build_cmd(&args) {
                Ok(cmd) => built.push(cmd),
                Err(m) => return errors::failure_msg("usage", "", &m),
            }
        }
        match self.conn.query_pipeline(built) {
            Ok(values) => List::from_values(
                values.into_iter().map(|v| robj::to_robj(reply::from_value(v, false))),
            )
            .into(),
            Err(e) => errors::failure(&e),
        }
    }
```

```r
#' Run several commands in one round trip
#'
#' @param con A connection from [redis_connect()].
#' @param cmds A list. Each element is one command as a character vector or a
#'   list, for example `list(c("SET", "a", "1"), list("INCRBY", "a", 5))`.
#' @return A list with one reply per command. A command that failed gives a
#'   `redis_error` condition object in its slot. It is returned, not thrown.
#'   In cluster mode, one failed command can fail the whole pipeline.
#' @export
redis_pipeline <- function(con, cmds) {
  call <- sys.call()
  check_con(con, call)
  if (!is.list(cmds)) stop(usage_error("cmds must be a list of commands", call))
  if (length(cmds) == 0L) return(list())
  packed <- lapply(cmds, function(cmd) as_args(as.list(cmd), call))
  run_command(con, function(ptr) ptr$pipeline(packed), call)
}
```

```r
#' Make an ElastiCache IAM token
#'
#' @param cache_name The replication group ID or the serverless cache name.
#'   This is not the endpoint DNS name.
#' @param user_id The ElastiCache user ID. AUTH uses it as the user name.
#' @param region The AWS region, for example `"eu-west-1"`.
#' @param serverless `TRUE` for ElastiCache Serverless.
#' @param credentials A list with `access_key_id`, `secret_access_key` and
#'   `session_token`. If `NULL`, `paws.common::locate_credentials()` finds them.
#' @return A token string, valid for 15 minutes.
#' @export
elasticache_iam_token <- function(cache_name, user_id, region, serverless = FALSE,
                                  credentials = NULL) {
  if (is.null(credentials)) {
    if (!has_paws()) {
      stop(usage_error(paste(
        "IAM authentication needs the package 'paws.common'.",
        "Install it with install.packages(\"paws.common\")."
      )))
    }
    credentials <- paws.common::locate_credentials()
  }
  amz_date <- format(Sys.time(), "%Y%m%dT%H%M%SZ", tz = "UTC")
  iam_token_at(cache_name, user_id, region, serverless, credentials, amz_date)
}
```

```r
#' Store and read R objects
#'
#' `redis_set_object()` stores `serialize(value)`. `redis_get_object()` reads
#' the bytes and calls `unserialize()`. Only read keys that you wrote with
#' `redis_set_object()`: `unserialize()` on untrusted data is not safe.
#'
#' @param con A connection from [redis_connect()].
#' @param key The key.
#' @param value Any R object.
#' @param ex Expiry in seconds, or `NULL` for no expiry.
#' @export
redis_set_object <- function(con, key, value, ex = NULL) {
  bytes <- serialize(value, NULL, xdr = TRUE)
  if (is.null(ex)) {
    redis_cmd(con, "SET", key, bytes)
  } else {
    if (!is.numeric(ex) || length(ex) != 1L || is.na(ex) || ex < 1 || ex != trunc(ex)) {
      stop(usage_error("ex must be a positive whole number of seconds"))
    }
    redis_cmd(con, "SET", key, bytes, "EX", ex)
  }
  invisible(NULL)
}

#' @rdname redis_set_object
#' @export
redis_get_object <- function(con, key) {
  bytes <- redis_cmd_raw(con, "GET", key)
  if (is.null(bytes)) NULL else unserialize(bytes)
}
```

~~~~markdown
# redisrs

redisrs is a Redis and Valkey client for R. It uses the Rust crate `redis-rs`. It supports TLS, Redis Cluster, pipelines, and IAM authentication for AWS ElastiCache and MemoryDB.

## Installation

You need Rust (`rustc` and `cargo`). Install it from https://rustup.rs.

```r
remotes::install_github("<owner>/redisrs")
```

## Usage

```r
library(redisrs)
con <- redis_connect("redis://localhost:6379")
redis_cmd(con, "SET", "greeting", "hello")
redis_cmd(con, "GET", "greeting")
redis_pipeline(con, list(c("INCR", "n"), c("INCR", "n")))
redis_set_object(con, "model", lm(mpg ~ wt, mtcars), ex = 3600)
redis_close(con)
```

## AWS ElastiCache with IAM

Install `paws.common` for IAM authentication. It finds your AWS credentials.

```r
con <- redis_connect_elasticache(
  endpoint = "my-cache-abc123.serverless.euw1.cache.amazonaws.com",
  cache_name = "my-cache",
  user_id = "app-user",
  region = "eu-west-1",
  cluster = TRUE,
  serverless = TRUE
)
```

The client makes a new token at each connect and reconnect.

## Errors

Each error has one of these classes: `redis_error`, `redis_connection_error`, `redis_auth_error`, `redis_usage_error`. All of them also have the class `redisrs_error`.

## Limits

Version 1 has no Pub/Sub, Streams helpers, Sentinel, or asynchronous mode. Stream commands work through `redis_cmd()`.
~~~~
